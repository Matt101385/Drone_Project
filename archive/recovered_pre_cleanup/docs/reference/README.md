# Reference

This folder records the current working setup for the drone project.

Use these files for final reports, field checks, and rebuild notes:

| File | Purpose |
| --- | --- |
| `pi5_environment_reference.md` | Raspberry Pi 5 model, OS, Python, and package environment. |
| `pixhawk_px4_reference.md` | Pixhawk 6X, PX4, TELEM2 wiring, RC mode, and safety settings. |
| `realsense_d435i_reference.md` | Intel RealSense D435i detection and runtime settings. |
| `lidar_reference.md` | Reported LiDAR; details and integration status to confirm. |

Historical notes and prototypes are preserved under `archive/`. `docs/reference/` records current known facts; unverified details are marked as such.

Update this folder whenever the hardware, software versions, startup commands, or wiring change. Development and verification notes are under `docs/development/`.
