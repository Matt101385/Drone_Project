# 04 Raspberry Pi Project Idea Study Notes

## Purpose

Summarize the project inspiration from the video `Every Developer Needs a Raspberry Pi` by Sam Meech-Ward.

## Core Idea

A Raspberry Pi is a low-cost platform for testing real-world software and hardware ideas.

Useful directions:

- Deployment practice.
- Automation.
- Computer vision.
- Lightweight AI.
- Hardware interaction.
- Edge-device prototyping.

## Relevance to Drone Project

The Pi can act as:

- Companion computer.
- Camera-processing node.
- Local dashboard host.
- Sensor/GPIO interface.
- Lightweight AI inference device.

## Suggested Project Path

1. Build a ground-side monitoring/control prototype.
2. Add camera capture and streaming.
3. Add visual recognition.
4. Add sensor or GPIO interaction.
5. Integrate flight-controller communication.
6. Move toward visual-following behavior.

## Key Takeaway

The Raspberry Pi is the bridge between software development and the physical drone system.
